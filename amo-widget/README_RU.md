# Виджет RATS / ATOS 5.2.0

На основе принятого приватного архива владельца 5.1.0. WebRTC в браузере и обратный звонок на телефон менеджера. Подтверждение клавишей 1 удалено.

[Установка сервера, интеграции и проверка](../docs/AMO_WIDGET_SETUP_RU.md). [Архитектура](../docs/AMO_TELEPHONY_ARCHITECTURE_RU.md).

`ratsUrl` — публичный HTTPS origin ATOS. Виджет использует `$authorizedAjax` и `/api/v1/amo/widget/v2`; сервер проверяет подписанный `X-Auth-Token`, account/client/user и владельца заявки. ID и секрет этой же приватной интеграции вводятся в зашифрованные настройки ATOS. ID пользователя из тела запроса не считается удостоверением.

Для браузера устанавливаются персональные PJSIP-устройства, WSS, DTLS/ICE и при необходимости TURN. Пароль транка и секрет интеграции в браузер не передаются. JsSIP 3.13.9 собран локально, CDN не требуется.

```bash
npm --prefix amo-widget ci
npm --prefix amo-widget run build
python scripts/build-amo-widget.py
```

Готовый `widget.zip` лежит в корне репозитория. В архиве manifest/script/style, i18n, изображения, SIP bundle и лицензии. node_modules и инструменты разработки не включаются. Обновить архив в существующей приватной интеграции amoCRM.
