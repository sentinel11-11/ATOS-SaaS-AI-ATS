# Виджет ATOS-ATS для amoCRM

Виджет запускает исходящий звонок из открытой карточки amoCRM:

`amoCRM → ATOS-ATS → MegaFon ВАТС` или `amoCRM → ATOS-ATS → Multicom/AMI`.

Он получает сущность через API виджета amoCRM, извлекает телефон и `responsible_user_id`, а затем отправляет в ATS:

```json
{
  "phone": "+79991234567",
  "crm_contact_id": 23571,
  "amo_user_id": 14322926,
  "route": "megafon_vats",
  "request_id": "amo-..."
}
```

## Установка приватной интеграции

1. Соберите архив `widget.zip` из корня репозитория и загрузите его в amoCRM как приватную интеграцию.
2. В настройках виджета укажите `https://axiomats.ru` (или публичный HTTPS-адрес ATS) в поле **Адрес ATS**.
3. В поле маршрута укажите `megafon_vats` для МегаФон ВАТС или `multicom_ami` для Multicom через AMI.
4. Разместите виджет в `lcard-1`, `ccard-1` и `comcard-1`.
5. Убедитесь, что frontend-адрес amoCRM разрешён CORS ATS. Для стандартного аккаунта это `https://<subdomain>.amocrm.ru`.

В карточке сделки виджет берёт первый связанный контакт и его номер. В карточке компании он использует телефон самой компании. Если API виджета недоступен, остаётся резервное чтение `tel:` из DOM.

## Настройка ATS

- Контакт должен быть синхронизирован в ATS и иметь тот же `crm_contact_id`, либо совпадающий нормализованный номер телефона.
- Для каждого оператора задайте соответствие **внутренний номер/extension МегаФон или Multicom → amo user ID** в `operator_user_map`.
- Включите живые звонки только после настройки тестового списка номеров и проверьте, что выбранный маршрут настроен.
- Для МегаФон ВАТС укажите CRM webhook `https://axiomats.ru/api/megafon/events`, а ключ передавайте в `X-CRM-Token` или `Authorization: Bearer`.

Кнопка виджета не вызывает amoCRM напрямую и не хранит access token в браузере. ATS проверяет origin amoCRM, проверяет amo user по серверному токену и выбирает оператора по серверному mapping.
